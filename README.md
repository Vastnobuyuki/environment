# 环境

> 环境质量报告书的 OCR 识别与结构化处理
> 从报告文档到可用数据，一套可复现的抽取流程。

## 项目简介

本仓库围绕「环境质量报告书」的自动化处理展开：

- **识别** —— 用 OCR 将报告书（PDF / 扫描件 / Word）转为可编辑文本
- **抽取** —— 按《环境质量报告书编写技术规范》的结构与字段规则，抽取关键指标
- **整理** —— 汇总为下游可直接使用的结构化数据集

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `ocr_app.py` | OCR 识别与文本抽取脚本 |
| `main.c` | C 语言主程序 |
| `地表水（1）.zip` | 地表水环境质量相关数据 |
| `数据（1）25.7.3（2）.zip` | 原始数据包 |
| `环境质量报告书编写技术规范（1）.pdf` | 报告编写规范，作为抽取与校验依据 |
| `第一部分（1）.docx` / `第二部分docx（1）.docx` / `第三部分（1）.docx` | 报告书正文文档 |

## 快速开始

```bash
git clone https://github.com/Vastnobuyuki/environment.git
cd environment

# 安装依赖后运行识别脚本（参数说明见脚本内注释）
python ocr_app.py
```
